# Dashboard

**Daniels Planer** (`planer.html`) – persönliches Life Dashboard als eine einzige HTML-Datei.
Einfach per Doppelklick im Browser öffnen, läuft offline (nur die Schriften kommen von Google Fonts, mit Fallback).

- Heute, Kalender (Monat/Woche/Tag/Agenda, Drag & Drop, Wiederholungen, ICS), Routinen & Habits (Fokusmodus, Heatmap),
  Notizen (Markdown, Vorlagen, Daily Notes, Bilder), Aufgaben (Time Blocking), Rückblick, Tools, Einstellungen
- Daten liegen lokal in IndexedDB; Backup als JSON unter *Einstellungen → Daten & Backup*
- `Strg/⌘ + K` Command Palette, `?` zeigt alle Tastenkürzel

Die verlinkten Tools (`haushaltsplan.html`, `privatkredit-tracker.html`, `modeluebersicht.html`) gehören in denselben Ordner.
